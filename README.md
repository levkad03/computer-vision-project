# Foosball tracker

![Demo screenshot](assets/demo.jpg)

This repository contains code for **Foosball tracking**

## Technology Stack

[![My Skills](https://skillicons.dev/icons?i=py,opencv)](https://skillicons.dev)

- python
- opencv
- numpy
- ultralytics

- pitch detection
- goal detection

## How to run

- upload [this video](https://drive.google.com/file/d/1UH68RhZsxKn8eopYqneZJLtZXt3tHC-f/view) into `data` folder

- install dependencies

```bash
pip install -r requirements.txt
```

- run the script

```bash
python src/main.py
```
